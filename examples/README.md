# Examples

Two artifacts that show what the product produces:

- [report-example.md](report-example.md): a full review of a small, deliberately sloppy screen, in the exact report format.
- [chart-example.md](chart-example.md): a filled chart, the project context every command reads.

The fixtures behind the report live in `packages/detect/test/fixtures/`. The app, the data, and the numbers are invented for the example; the findings are the ones the detector actually returns for those files.
